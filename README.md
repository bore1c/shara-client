# SHARA Client

A Fabric client mod for Minecraft 1.21.4.

## Features
- Fabric entrypoint
- module manager
- setting system
- config serialization
- basic HUD modules
- ClickGUI scaffold
- command system

## Build
```bash
./gradlew build
```

## Run client
```bash
./gradlew runClient
```

## Notes
This is a working scaffolding project intended to be extended into the full SHARA Client suite. It follows the Fabric 1.21.4 client mod pattern and is structured around the requested package layout.
